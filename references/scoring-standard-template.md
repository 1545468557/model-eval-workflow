# 打分标准模板

> 使用说明：复制本模板，为每个核心指标填写详细的打分规则。每个维度必须包含定义、权重、打分方式、档位锚点、正例、反例、易分歧点、硬性否决线。

---

## 统一执行规则

### 1. 独立评审
多位评审分别获得隐藏模型名称的同一稿件，各自判定，提交前不讨论。

### 2. 证据要求
每个不通过项必须记录：**规则编号 + 位置（集数/场次） + 原文/数据 + 原因**，不得只写"不够好""有问题"。

### 3. 争议处理
保留两人的原始结果，逐项复核争议证据；未裁定项标为"待裁定"，不得按通过处理。

### 4. 权重规则
不设置加权总分。核心指标均为独立必过门槛；一票否决项拥有否决权；GSB计分权重为0，仅作诊断参考。任何加权总分都不能挽救不通过项。

### 5. 计时规则
计入阅读、必要的资料核验、判断、编辑和自检；排除与任务无关的中断。跨集通读及全剧复核时间单独记录，平均分摊到总集数，加入各集耗时，避免隐藏人工成本。
